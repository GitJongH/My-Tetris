# My Tetris

브라우저에서 바로 실행되는 테트리스입니다. `index.html` 파일 하나로 되어 있고, 설치나 외부 라이브러리는 필요 없습니다.

## 플레이하기

**https://gitjongh.github.io/My-Tetris/**

## 실행 방법

로컬에서는 `index.html`을 브라우저로 열면 됩니다. Enter 키로 시작합니다.

## 조작

| 키 | 동작 |
| --- | --- |
| ← / → | 좌우 이동 (길게 누르면 연속 이동) |
| ↓ | 소프트 드롭 |
| ↑ / X | 시계 방향 회전 |
| Z | 반시계 방향 회전 |
| Space | 하드 드롭 |
| C / Shift | 홀드 (블록 하나당 1회) |
| P | 일시정지 |
| M | 음소거 |
| Enter | 시작 / 재시작 |

## 기능

- 7종 블록, 7-bag 랜덤, 다음 블록 4개 미리보기
- 홀드, 고스트 피스, 벽에 걸릴 때 밀어주는 회전 처리
- 점수, 10줄마다 레벨업(낙하 가속), 최고점수 저장(`localStorage`)
- 콤보: 줄을 지운 블록이 연속되면 보너스 점수(`50 × (콤보-1) × 레벨`)와 화면 팝업
- 움직이는 배경: 맥동하는 그라데이션, 불씨 파티클, 줄 삭제 시 충격파와 화면 흔들림
- 입체감 있는 블록(그라데이션, 베벨, 조작 중인 블록 글로우)
- 효과음 (WebAudio)

## 점수

| 삭제한 줄 | 점수 |
| --- | --- |
| 1줄 | 100 × 레벨 |
| 2줄 | 300 × 레벨 |
| 3줄 | 500 × 레벨 |
| 4줄 | 800 × 레벨 |

소프트 드롭은 칸당 1점, 하드 드롭은 칸당 2점이 추가됩니다.
